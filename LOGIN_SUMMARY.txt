                    TROUBLESHOOTING
================================================================================

Cannot reach localhost?
  → Try: http://127.0.0.1:5173
  → Restart Docker Desktop
  → Check firewall not blocking ports 5173, 8080

MFA code doesn't work?
  → Generate a new one (codes expire in 30 seconds)
  → Verify system time is correct
  → Check you copied the full 6-digit code

Connection refused?
  → Run: docker compose ps
  → Check all containers show "Up"
  → Restart: docker compose down then docker compose up -d

Wrong credentials?
  → Verify email spelling exactly as shown above
  → Confirm password is "Demo1234!" (case-sensitive)
  → Try a different account
